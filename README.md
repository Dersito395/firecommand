# Fire Command — Biosite

Página de links da Fire Command, aberta pelo celular a partir da placa NFC.

| Botão | Ação |
| --- | --- |
| Salvar contato | Baixa `contato.vcf` — (14) 99861-9590, e-mail, Instagram e logo |
| Pix | Abre painel com a chave (18) 99819-9298 e botão "Copiar chave" |
| Instagram | https://www.instagram.com/firecommand_br/ |
| E-mail | `mailto:firecommandbr@gmail.com` |

## Arquivos

| Arquivo | Papel |
| --- | --- |
| `index.html` | A página inteira (HTML, CSS e JS) |
| `contato.vcf` | Cartão de contato baixado pelo botão "Salvar contato" |
| `img/` | Logo (versão para fundo escuro e original), ícone e foto |

## Publicação

Site estático no GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

Para usar um domínio próprio (ex.: `firecommand.com.br`), informe-o em
**Settings → Pages → Custom domain** e aponte o DNS para o GitHub Pages.
Grave na placa NFC o endereço final (registro do tipo URL/URI).
